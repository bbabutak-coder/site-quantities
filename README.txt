Site Quantities - installable app package

Files (upload ALL of them to the same folder of your web host):
  index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png

To publish an update later: replace index.html and change the number in sw.js
(const V = "siteq-v1" -> "siteq-v2") so phones fetch the new version.
